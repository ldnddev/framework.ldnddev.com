Bar Chart Component Breakdown

Overview

The dd-bar-chart component renders a dependency-free set of horizontal bars for comparing labelled values. Each row pairs a text label and value with a proportional bar, so trends read clearly without any charting library.

This component is ideal for score breakdowns, category comparisons, and lightweight report visuals. In WordPress, configure it via a repeater of label and value rows with an optional tone per row. In Drupal, use a Paragraph type with a multi-value field for label, value, and tone.

Basic Usage

Wrap the chart in a dd-bar-chart figure with a visible <figcaption>. Each row uses a dd-bar-chart__row holding the label, value, and a decorative dd-bar-chart__bar. Apply a tone modifier per row where helpful.

CSS Modifiers (from _dd_bar_chart.scss)

The SCSS file defines the row layout, bar track, and fill, with tone modifiers driven by design tokens. Key modifiers include:

  • -good: Success-toned fill for a healthy row.
  • -warn: Warning-toned fill for a middling row.
  • -bad: Error-toned fill for a poor row.
  • No modifier: Default fill using neutral tokens for an unclassified row.

Accessibility and Best Practices

The label and value text are the accessible truth; the bars are decorative and marked aria-hidden="true". The chart is a <figure role="group"> named via aria-labelledby pointing at the visible <figcaption>, or by aria-label when there is no caption. The value is never truncated behind the bar at a 320px width or 400% zoom (WCAG 1.4.10 Reflow), and the fill grow-in animation is gated behind prefers-reduced-motion.
