Data Table Component Breakdown

Overview

The dd-data-table component is an accessible table with a caption, scoped header cells, and optional status cells that embed the dd-badge component. It wraps the table in a keyboard-focusable horizontal scroll region and supports optional column sorting and an empty state.

This component is ideal for report data, comparison grids, and audit result listings. In WordPress, configure it via a repeater of rows and a header definition, with a status column mapped to badge severities. In Drupal, use a Views table or a Paragraph type with structured field data.

Basic Usage

Wrap a semantic <table> with a <caption> and <th scope> headers inside the dd-data-table container. Status cells embed a dd-badge, and sortable columns use native header buttons. The scroll region and sorting behaviour are wired up by the component JS.

CSS Modifiers (from _dd_data_table.scss)

The SCSS file defines the table layout, cell padding, scroll region, and focus styling. Key modifiers include:

  • -dense: Reduces cell padding for compact, data-heavy tables.
  • No modifier: Default comfortable spacing for standard readability.

Accessibility and Best Practices

The <caption> names the table, and header cells use <th scope> for correct association. The scroll region receives tabindex="0", role="region", and an aria-label from the JS only when it actually overflows, so keyboard users can scroll without adding an empty tab stop otherwise. Sortable headers are native <button> elements with aria-sort set on the <th> (exactly one column non-none at a time), and sorting is fully keyboard-operable. The focus ring uses a high-contrast dark colour rather than the brand green so it stays visible on all cell backgrounds.
